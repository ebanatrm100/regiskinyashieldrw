# AI Image Generation Guide: what the assistant covers

Source: "AI Image Generation Techniques Guide" (owner's document). Everything is offline, in English, French, Kinyarwanda and Kiswahili (fr/rw/sw are drafts for fluent review).

| Guide section | Where in the assistant |
|---|---|
| Seven-step creation process | `image_guide_db` → img_process |
| 12 main techniques | img_techniques, img_diffusion, img_latent, img_crossattn |
| 12 prompt ingredients | img_ingredients; tool `improve prompt: …` |
| Weak vs strong prompt | img_weak_strong |
| Composition techniques | img_composition; tool `rule of thirds 1920x1080` |
| Improving the first result | img_improve |
| Common problems and fixes | img_problems + describe-your-problem finder |
| Training steps | img_training |
| What can/cannot be claimed | img_claims, img_prompt_tips |
| Six-exercise practice plan | img_practice; tool `score image: accuracy 4, …` |
| Glossary (14 terms) | "image generation glossary", "what is inpainting" |
| Further reading | img_reading |

Tools (`image_lab`): `improve prompt: …`, `score image: …`, `rule of thirds WxH`, `aspect ratio WxH`, `latent demo WxH`, `denoising demo`.

Honest limits: the app does not generate pictures (no image model connected); it never states private details of commercial models; no prompt formula is guaranteed; ingredient detection is keyword-based, a teaching aid.
